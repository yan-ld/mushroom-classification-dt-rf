# mushroom-classification-dt-rf
A data mining notebook that classifies mushrooms as edible or poisonous, using the Mushroom dataset (UCI) and comparing Decision Tree and Random Forest models

## Dataset
[Mushroom Classification (Kaggle/UCI)](https://www.kaggle.com/datasets/uciml/mushroom-classification)

## What this notebook covers
- Exploratory data analysis and handling of missing values
- Feature encoding and stratified train/test split
- Training and comparison of both models
- Performance metrics (accuracy, precision, recall, F1-score) and confusion matrices
- Feature importance analysis

## Results
Odor was the most important attribute between the two models
